# Keep Web Clone

A lightweight web clone of a notes app inspired by Google Keep.  
Client-side React app (Vite) with features:
- Create / edit / delete notes
- Pin notes
- Search
- Note colors
- Markdown preview (live)
- Import / Export notes as JSON
- Data persisted to localStorage

## How to run

1. Install dependencies
```bash
npm install
```

2. Start dev server
```bash
npm run dev
```

3. Open the URL shown by Vite (usually http://localhost:5173)

This repository is front-end only and intentionally stores data in the browser's localStorage.
